# Scope Governance

Baseline v0.2 has three primary modes:

- `maturity`
- `feature`
- `document`

Out of scope:

- automatic implementation by default,
- commits or pull requests,
- HTTPS servers,
- MCP runtime,
- remote analysis,
- vendored binaries or compilers.

Requests that broaden the skill beyond controlled planning and documentation must be postponed or split into a separate skill.
