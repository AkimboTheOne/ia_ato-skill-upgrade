# Feature Fit

Feature fit evaluates whether a request belongs in the current skill, needs clarification, should be postponed, or should become a separate skill.

Setup and onboarding improvements fit when they reinforce skill maturity without adding unrelated runtime behavior.

The local setup pattern is considered a feature-fit strength when the repository already contains:

- root `setup-skill.sh`,
- `.venv`-only installation,
- PEP 668 guidance,
- explicit Python dependency boundary.
