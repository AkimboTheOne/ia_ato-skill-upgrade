# Acceptance Checks

- CLI is installable.
- `context` produces JSON.
- `capabilities` lists the three primary modes.
- `doctor` reports repository status.
- `validate` checks baseline structure.
- `ask` classifies natural language.
- `iterate` writes session notes and JSON.
- `./setup-skill.sh` completes onboarding through local `.venv`.
- Setup does not require global Python package installation.
- `review external --read-only` writes outputs only under the active workspace exports directory.
- `run --payload-file` returns an object with `operation` and `result`.
- Sample skill fixtures exercise mature and weak setup paths.
- `document change --self-review --write` is blocked.
- `document change --review-report` treats external review JSON as detected evidence.
- `validate` checks contract schema hygiene.
